# 🩺 Prompt Doctor

Prompt Doctor is an AI-powered prompt analysis and optimization tool that helps users write better prompts for Large Language Models (LLMs) such as ChatGPT, Claude, Gemini, Grok, and other AI assistants.

## ✨ Features

- 🔍 Analyze prompts for clarity and effectiveness
- 💡 Suggest improvements and optimizations
- 🎯 Generate high-quality prompts for different use cases
- 📚 Support for multiple AI models
- ⚡ Real-time prompt feedback
- 📝 Prompt templates for common tasks
- 🚀 Beginner-friendly interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/prompt-doctor.git

cd prompt-doctor
```

### Install frontend

```bash
npm install
```

### Install backend

```bash
pip install -r requirements.txt
```

## Environment Variables

Create a `.env` file.

```env
OPENROUTER_API_KEY=your_api_key
OPENAI_API_KEY=your_api_key
```

## Start Frontend

```bash
npm run dev
```

## Start Backend

```bash
python app.py
```

or

```bash
uvicorn main:app --reload
```

## Example Workflow

1. Enter a prompt.
2. Click **Analyze**.
3. Review AI suggestions.
4. Improve the prompt.
5. Generate the optimized version.
